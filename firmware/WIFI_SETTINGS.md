## 使用

2026-10-12后续新增：网络页支持Wi-Fi关闭/开启，保留凭据；每次取得IP自动触发一次SNTP校时及RTC写回，详见[TIME_SYNC.md](TIME_SYNC.md)。实际启动自动连接、一次SNTP与RTC写回已通过日志核验；手动Wi-Fi开关及完全关机后的场景仍待验收。

2026-10-12字体修复：密码输入框文字和遮掩圆点为白色，光标文字为白色，占位提示浅灰色；显隐切换沿用同一颜色规则。

该修复固件3972736字节已刷入，压缩构建、哈希校验与12秒启动日志通过；应用副本 `backup/pet_watch_wifi_white_password_20261012.bin`。视觉可读性待用户确认。

1. 运行时短按 BOOT 进入设置，点击「网络」，自动扫描 2.4GHz Wi-Fi。
2. 点选网络，输入密码；英文 QWERTY 四行键盘支持 ABC/abc、1# 数字符号、顶部 #+= 额外符号、空格、删除、密码显隐与确认。
3. 连接期间显示进度状态；成功显示网络名、IP 和保存结果。认证失败、无网络与超时提供提示，返回列表可重试。
4. 连接成功后保存配置；下次开机自动连接，连接丢失后约每30秒尝试恢复已保存网络。新密码失败不会覆盖之前保存的可用配置。
5. 设置子页短按 BOOT 回首页，首页再按回宠物；PWR 短按退出设置回宠物。黑屏时 BOOT 直接进入设置。

支持开放网络与 WPA2/WPA3 Personal。企业认证、WEP/WPA1-only 条目不可选。当前不提供隐藏 SSID 手工输入；密码支持8–63字符（开放网络不用密码），不支持64位十六进制 PSK。

## 实现依据与边界

- 官方微雪包 `examples/esp-idf/03_esp-brookesia` 是应用 UI Demo；本次复用现有官方 BSP，未迁入整套 Brookesia。
- 键盘依据官方包的 LVGL `examples/widgets/keyboard/lv_example_keyboard_2.c` 自定义映射模式；网络依据本机 ESP-IDF5.4.2 station/scan API 和事件模型。
- 独立 Wi-Fi worker 执行扫描、连接与保存；网络事件只更新同步状态，LVGL 定时器读取快照，网络线程不操作界面。
- RAM Wi-Fi 配置、独立 NVS `pet_network` 保存成功配置；不输出密码。NVS 未启用加密，设备物理存储仍需后续产品级保护方案。
- 扫描最多取20个记录并按SSID去重；不展示空/隐藏SSID。扫描结果中的加密网络以 * 标注。
- 中文界面使用本地字体生成的24px字形子集和 Montserrat 拉丁字符回退；网络名称中未收录的中文/其他字符可能显示缺字，完整网络名字体待完善。
- Wi-Fi 已初始化并保持站点模式，使用 modem power save；不是按需彻底断电方案，尚未测量新增功耗。
- 2026-10-14：默认继续保持连接；可选 `pet_power/sleep_wifi_off` 底层配置只在黑屏且无网络应用需求时自动停网。配置未接设置UI。手动关闭优先，自动停网后需在原网络页手动开启，重启仍尝试联网。SNTP已使用网络需求保护，详见[电源管理](POWER_MANAGEMENT.md)。
- 内存修复：固定竖屏关闭BSP软件旋转的额外DMA缓冲，保留原SPI完成回调与40行绘图缓冲；允许Wi-Fi/LwIP优先使用PSRAM，并关闭Wi-Fi IRAM吞吐优化，避免无线组件挤占内部显示内存。补丁为 `patches/fixed_portrait_memory.patch`，依赖重建后需重施。
- 设置闲置60秒后回宠物，随后沿用15秒进时钟和时钟60秒息屏；扫描连接不阻塞显示。设置字体24px；较长提示允许换行。

## 2026-10-14 离线超时策略

网络页“离线15分钟关闭”默认关，点击切换并保存到pet_network/offline_off，失败提示“未保存，请重试”且保留原值。连续离线计时由既有工作线程处理，启动连接失败及30秒检查粒度会带来延迟，因此是约15分钟，不承诺秒级截止。成功联网或处理Wi-Fi开关后重置计时；手动刷新/连接工作先完成，超时检查在空闲轮次执行。无已保存网络也可在离线超时后关闭。

超时停止经过统一电源需求锁，后台应用持有NETWORK需求时暂缓，下次空闲检查再试。自动关闭显示“离线超时，已关闭”；手动开启后可重新连接或扫描。亮屏不自动开启。每次开机仍默认开启Wi-Fi；策略开关本身持久化。默认保留Wi-Fi决策不变。模拟保存失败/圆角布局通过；15分钟真实超时与手动恢复待真机验收。

## 2026-10-14 重连退避

连续连接失败后，按每一轮结束计时，等待30秒→60秒→120秒→300秒，后续上限300秒。每轮仍最多尝试两次，不把两次内部尝试误称两轮。使用单调时钟，不受RTC/网络校时变化影响；等待由现有队列30秒检查执行，实际发起时间可稍晚，不额外创建任务或阻塞手动操作。

手动选择网络或手动重新开启Wi-Fi立即处理并重置退避；成功联网重置。手动刷新列表不清空已有退避进度，不用反复扫描绕过等待；刷新后无IP可继续按原截止时间重连。未保存网络不自行选择陌生网络。已取得IP不额外重连。

15分钟自动关闭配置及开机默认开启规则保留；超时检查每30秒进行，与重试截止时间独立，后台联网需求仍保护停止动作。此更新替代此前固定每30秒启动一轮的自动重连行为，不改变UI、不更改凭据或充电参数。

验证：纯策略测试覆盖全部阶梯、上限、截止前后、重置与独立关闭计时；现有电源需求保护测试通过。真实完整5分钟阶梯、人工联网恢复及耗电收益需单独验收；不能将重试次数减少比例当整机节电比例。
