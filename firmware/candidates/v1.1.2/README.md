## 本版功能

- 板载QMI8658硬件计步初始接入，主屏及黑底时钟显示当天步数。
- 按日期保存，保留最近366个有记录的日期；每分钟有变化才写，跨日和正常软件重启前保存；历史界面未加入。
- 主屏顶部实际电量、日期旁加粗步数；黑底日期/电量同行，下方浅灰底黑字STEP胶囊。按用户附图校准字号、比例和位置；未知/充电/USB/计步不可用/保存失败有对应状态。
- 桌面时钟开关同时控制主屏时间、日期与步数；关闭后保留电量，开启后三项一起恢复。黑底时钟、后台计步及保存不受影响。
