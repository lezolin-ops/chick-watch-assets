## 导出

一天后连接电脑，先导出再刷其他固件或清除数据。在项目ESP-IDF Python环境运行：

```
python firmware/tools/export_battery_log.py --port /dev/cu.usbmodem1101 --output firmware/backup/battery-day.csv
```

该工具重启设备以触发历史输出，通常十余秒，45秒超时；只写电池记录到CSV，不写网络名称和密码。可以用`--input`读取已有启动日志。未收到完整BATLOG_END则报错，不交付残缺数据。记录按序号排序；时间无效、校时跳变、重启造成的运行时间回零须分段处理。

分析排除USB/充电区间，保留读数失败与缺口。比较电量与电压趋势及状态变化，不能从电压下降比例推导电流、精确耗电量或增加的续航小时数。用户起始观察100%，实际读取结果需由设备确认；无需完整放电，正常使用即可。
