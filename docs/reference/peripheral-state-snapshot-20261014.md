# 闲置外设真实快照 · 2026-10-14

只增加诊断接口，未写外设配置、未初始化音频或传感器，未改变供电和充电参数。开机及首次黑屏（约62.12秒）两份快照完成，读取到的控制寄存器完全一致。功放GPIO46两次InputEn=1、OutputEn=0、Pulldown=1，实际读取电平0。指令/状态与电流测量分开。

| 对象 | 真实读数 | 结论与下一步 |
|---|---|---|
| QMI8658，0x6B | WHOAMI=05，REV=7C，CTRL1=20，CTRL7=00 | 加速度/陀螺仪未启用；官方SensorLib powerDown使用的CTRL1 bit1未设置，可考虑补齐芯片关断，但不是一直在采样 |
| ES8311，0x18 | ID=83/11，RESET=1F，CLK01/02=00/00，SYS0D=FC、0E=6A、12=02、14=10 | 多项与官方suspend末态一致，但不是完全一致；已有显著关断配置，不当作全速音频工作，不盲写完整初始化 |
| ES7210，0x40（按BSP器件/地址映射） | CLOCK01=20，POWER06=00，MIC47～4A=00，MIC4B/4C=FF | 分组关断已有设置；与官方stop的CLOCK01=7F、POWER06=07、MIC47～4A=FF不同，可考虑完整待机。地址与寄存器响应不是本轮独立芯片ID鉴定 |
| 功放控制GPIO46 | 下拉输入，实际0，未输出驱动 | BSP配置为高电平使能，当前未观察到使能高电平；不等于电流为零或整个音频电源已断开 |

优先候选：对闲置QMI补齐powerDown、对ES7210核对完整stop及恢复；ES8311先维持，不初始化未使用链路再去关它。具体写入必须逐项保留/恢复原状态，兼容未来应用，不直接切共用3.3V。本轮只完成检查，没有实施以上待机优化，没有估计未经测量的节电电流或小时数。

依据：本地官方示例SensorLib的SensorQMI8658.hpp（CTRL7 bits0/1与powerDown的CTRL1 bit1）；当前esp_codec_dev ES8311 suspend/ES7210 stop及BSP pa_reverted=false配置。真实原始日志留本机firmware/backup/idle_peripherals_final_20261014.log，不公开完整网络日志。
