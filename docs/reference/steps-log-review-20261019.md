## 启用状态

本次实际读回CTRL1=40、CTRL2=07、CTRL5=01、CTRL7=01、CTRL8=90，与现有驱动配置匹配。按驱动所依据的SensorLib寄存器定义：CTRL7的加速度位为1、陀螺仪位为0；CTRL2对应±2g/62.5Hz；CTRL8 bit4为计步使能、bit7为命令握手配置。这里证明的是配置位和通信，并不独立证明此芯片修订的内置算法有效。芯片手册仍未完成审阅，不断言本芯片一定支持或不支持硬件计步。

本次日志恢复成功，不再有旧版本的ESP_ERR_INVALID_STATE退出。诊断由正常计步读取成功路径执行，原始计数寄存器可读。

## 当前日志的边界

固件不是持续记录每次加速度/计步读取：启动打印配置，收到串口STEPS_STATUS时才输出一次原始计数及三轴快照；常规每2秒读取计数，每分钟有变化才写日步数到NVS。日历史不是三轴运动日志。先前“原始步数一直为0”的准确表述应为“已采集到的这些快照均为0”。

用户实际佩戴仍不计数，产品功能未验收。下一步需要有明确起止和人工步数的运动采样，比较加速度与原始计数；若连续运动确认加速度有效而硬件计数不变，再据此选择修复内置配置或转软件算法。此次仅核对与采集日志，没有改算法、刷固件或声称计步已可用。
