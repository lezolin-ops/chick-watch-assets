日期：2026-10-19（北京时间）。来源：[QST官方QMI8658C Datasheet，13-52-27 Rev A](https://www.qstcorp.com/upload/pdf/202210/13-52-27%20QMI8658C%20Datasheet%20Rev%20A%20%281%29.pdf)，88页。已读计步相关段落及寄存器/握手内容（重点印刷页41、47、64～66），不是全册通读；网页PDF截图接口失败，表格位域含糊处不据此猜测修改。

## 官方说明与本项目对照

- 第11章明确列有硬件计步引擎，以加速度工作，要求Non-SyncSample；不能据社区评论断言所有C型号无计步。
- 参数需在加速度/陀螺仪关闭时分两组通过CTRL9配置；之后启用加速度及计步位。项目有对应流程，已读回启用状态，但不能证明参数被算法正确采用。
- 手册提供连续步确认及分批输出参数，阈值应按佩戴运动调校。项目参数是示例初值，未经实际行走标定。
- 第11.5节给出24位计数读取，第11.6节说明计步使能由0到1等操作会清计数；轮询不要求保持CPU持续唤醒。
- 手册与板载REV=7C之间的硅版本/算法匹配尚未证实；本次未修改或刷写固件。

## 省电关系的证据边界

当前方案没有通过电源管理切断IMU供电，常规工作用统一AWAKE需求保护并在读取间隔释放。已有USB日志证明面板DISPOFF/SLPIN后仍可读取计数与三轴，不能证明传感器被黑屏流程关闭。

但USB会阻止实际CPU自动轻睡眠：该日志不构成电池态轻睡眠路径验收，不能以此完全排除睡眠引脚/驱动时序交互。严格归因仍需亮屏/息屏同条件运动对比，并区分面板休眠与CPU轻睡眠。当前优先核对计步配置和实际事件/计数变化，不擅自关闭既有省电机制或Wi-Fi。
