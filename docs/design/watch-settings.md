# 手表设置页设计

统一规范见 [UI / UE设计规范](watch-ui-ux-guidelines.md)。以下保留页面设计方向；涉及当前按键、闲置退出、安全区及未实现能力时，以统一规范和实现说明为准。

状态：设置入口、手表直接配网、亮度持久化已实现（待真机验收）；OTA 仍未实现。真机实现说明见 `firmware/WIFI_SETTINGS.md`。

## 入口与返回

- 运行状态下短按 BOOT 打开设置，暂停宠物动画。
- 设置首页再短按 BOOT 返回宠物；子页短按 BOOT 返回设置首页。屏幕左上角提供相同的返回操作。
- 黑屏时短按 BOOT 唤醒并直接进入设置；退出回到宠物页面。
- PWR 保留原有电源与时钟交互。设置中短按 PWR 退出设置并回到宠物页面；下载/写入期间不允许切页，长按硬件关机行为不改。
- BOOT 运行时按键与上电下载模式分开：上电时按住 BOOT 仍是芯片下载模式，不可改为设置。
- 设置页面60秒无操作退出回宠物，再沿用15秒进入时钟、时钟60秒黑屏的流程；设置中不受宠物15秒计时打断。未来更新安装期间的超时例外需随OTA实现定义。

## 首页

410×502 竖屏，固定深色 AMOLED 风格，大字号、三行设置，无滚动。

- 顶部：返回按钮、设置标题。
- 网络：图标、标题「网络」、副标题「未连接」/当前 Wi-Fi 名称、进入箭头。
- 屏幕亮度：太阳图标、标题、副标题「当前 50%」、进入箭头。
- 系统更新：图标、标题、副标题「当前版本 …」/「有新版本」、进入箭头。
- 底部：轻量提示「按 BOOT 返回」。不显示装饰性仪表或宠物动画。

标题建议 32px，行标题 28–30px，辅助信息 20–22px。行高约 100px；触摸区域至少 48×48px。左右安全边距 24px；上下避开圆角。

## 屏幕亮度

- 点击首页「屏幕亮度」进入子页，显示大号百分比与横向滑条。
- 默认 50%，范围 10%–100%；2026-10-12用户明确要求恢复100%上限，真机滑条使用整数百分比。量产前需在实际供电条件下核验最大亮度，现有记录曾出现 USB 供电全亮电压跌落。
- 真机实现时拖动实时预览，松手后保存至 NVS，避免拖动过程中频繁写入；重启保留。
- 用户亮度用于宠物与设置页面。时钟页保留 10% 低亮度，黑屏亮度仍为零，返回宠物/设置恢复用户亮度。
- 2026-10-12新增桌面时钟开关设计需求，替代此前不提供时间开关的设计限制；尚未实现。独立时钟页及开机、唤醒、自动息屏规则沿用。见[桌面时钟设计](home-clock.md)。
- 交互预览仅更新百分比和首页摘要，不控制真实屏幕亮度。

## 网络子页

- 未连接：显示「尚未连接 Wi-Fi」，主按钮「开始配网」。
- 已按用户要求改为手表直接配网：扫描列表、选择网络、全屏英文密码键盘。手机辅助配网保留为此前设计探索，不是当前实现。
- 配网中：显示连接指引和状态，允许取消，不展示假二维码或未实现的热点名称。
- 成功：显示网络名称和「已连接」，提供「更换网络」。
- 失败：明确区分找不到网络、密码错误、连接超时，允许重试。
- Wi-Fi 密码不显示在首页，不写入日志。检查更新时按需联网。

## 系统更新子页

- 先显示真实固件版本和「检查更新」。接入前显示「更新功能待接入」，不可假装检查真实服务器。
- 无网络：显示「请先连接 Wi-Fi」，提供「去配网」。
- 无新版：显示「已是最新版本」及检查时间。
- 有新版：版本号、大小、简短更新内容，按钮「下载并更新」，支持稍后。
- 首版仅在 USB/充电供电满足条件时安装；电池阈值需要真机验证后确定。
- 下载：进度与取消。固件校验通过后进入安装状态，安装中禁用返回和重复更新。
- 完成：提示将重启。首次启动做关键功能检查，失败自动回退。OTA 双分区、校验和回退需实际实现与断网/断电验证。
- 宠物存档、网络设置、亮度设置独立于应用分区；更新不清除用户数据。

## 预览边界

交互预览包含 BOOT 进入/返回、亮度滑条、网络和更新子页。任何网络连接、版本号和更新过程均为明确标注的演示状态；未执行联网、写入设备或烧录。

## 当前确认版本：v5（2026-10-12）

用户明确选择v5桌面时钟设计，状态为已确认（待实现）。采用大号卡通时间、中文月日与星期、纯色暖白且无阴影/描边/底板；替代此前v6英文日期探索。设置开关同时控制时间与日期；独立时钟页、实体按键及息屏规则沿用。以上v2–v6迭代描述为历史过程，当前实现依据见[已确认v5设计](home-clock.md)。默认开启与保存选择仍为建议；精确安全区、可读性及真机验收待实现验证。
