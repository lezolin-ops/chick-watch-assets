## 锁定项

- 眉毛全程细线条、粗细一致，只改变下压角度和幅度（A1 轻皱 → A2 明显倒八字 → A3 压低挤近），不突然变粗黑浓眉（首版 A2/A3 眉变粗，已重抽）。
- 眼睛全程与基准一致：纯黑圆眼珠 + 一个极小白色高光点，**无白色眼白、不露出眼白**（首版 A2/A3 误加眼白，已重抽）。
- 身体等比、圆胖比例、头顶呆毛、腮红位置全程不变；扁平平涂、无描边、无渐变、无投影、暖米白背景 #FEFCF4。
- 调色板：身体黄 #FDD649、腮红 #FEA879、嘴内腔 #F56432、脚 #FD8825。生成帧身体均值约 (254,215,80)，定稿按整体增益校到 #FDD649，不强制 H/S。
- 双脚贴同一水平线、水平居中；身体不前倾、不拉长压扁。

- 校色产物在 `graded/`：整体增益把身体黄均值拉到 #FDD649，紧 mask 只动身体，腮红/喙/脚/眼/背景不改（非身体区平均变化 0.0）；原帧保留在根目录。
