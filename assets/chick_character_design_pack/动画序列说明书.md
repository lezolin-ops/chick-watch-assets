# 动画序列说明书

> 电子宠物小鸡各情绪动画的统一结构、帧角色与序列链。产品规则见根目录 `PRODUCT_UPDATES.md`（PU-060 首尾常态帧、PU-062 悲伤、PU-063 睡觉、PU-064 惊讶、PU-065 得意、PU-066 害羞、PU-067 害怕）。
> 本文件只描述序列设计与帧角色，不含固件实现；GIF/视频仅作节奏预览，定稿用清晰 PNG。

## 0. 通用规则（所有情绪共用）

### 0.1 身份锚点与不变量

- **唯一身份锚点**：`00_front_reference.png`（仓库内相对本目录），颜色、比例、造型只认它；衍生帧逐张对照。
- 色板：身体黄 #FDD649、腮红 #FEA879、嘴内腔 #F56432、脚 #FD8825、背景 #FEFCF4。
- 风格：扁平平涂、无描边、无渐变、无投影；身体全程等比，不拉长压扁凑高低。
- 眼睛默认：纯黑圆眼珠+一个极小白色高光点，**无白色眼白/眼圈**；例外眼型见各帧（得意半眯斜缝、睡觉闭眼弧线）。
- 表情递进只改角度/幅度，眉线粗细、颜色深浅保持一致，不突然变粗黑浓眉，也不把眉删掉。

### 0.2 三种类型（决定要不要序列）

| 类型 | 代表 | 结构 | 帧量 |
|---|---|---|---|
| 爆发式触发情绪 | 生气、开心、悲伤 | `N → 递进帧 → N`，首尾常态帧闭合 | 3+ 帧 |
| 轻量情绪 | 惊讶、得意、害羞、害怕 | 可直接切换，需要回待机时再补 N 首尾 | 1–2 帧 |
| 待机/状态 | 睡觉、发呆、放空、无聊、生病 | 单张静态 + 程序微动态（呼吸/眨眼） | 1 帧 |

### 0.3 衔接与生产规则

- **触发式单次情绪**：`N 常态 → 情绪关键帧序列 → N 常态`，首尾同一张定稿常态帧，天然闭合。
- **持续无限循环情绪**（一直生气/开心不回待机）：用情绪序列自身首尾闭合，不把 N 插进每轮中间。
- 常态帧只作进出场公共帧，**不插进情绪序列内部重复拼帧**；不另造临时休息帧/旧底座。
- 校色：整体增益（身体黄帧均值→#FDD649，逐通道乘增益、保留明暗渐变），只动身体，腮红/喙/脚/眼/背景不改；**禁止逐像素强制 H/S**。
- 对齐：按黄色身体锚点等比缩放整帧，不用整图包围盒（否则抬脚/张翅导致身体忽大忽小）。
- 预览 GIF/AI 视频只看动作方向，**不回读当素材**；定稿一律清晰 PNG，程序补间排帧。

### 0.4 帧命名

| 码 | 含义 |
|---|---|
| N | 常态帧（公共进出场） |
| A# | 生气递进帧（起气/小喊/大怒/收势） |
| S# | 动作姿态帧（跺脚提脚/踩下；悲伤递进另列 S#，按目录区分） |
| E# | 惊讶（E1 轻惊 / E2 大惊） |
| P# | 得意 |
| H# | 害羞 |
| F# | 害怕（F1 警觉 / F2 害怕） |
| Z# | 睡觉（待机） |
| K# | 开心（历史目标链，避开与害羞 H 冲突） |

## 常态帧 N

- 文件：`angry_keyframes/graded/frame_00_neutral.png`（定稿后可上移到公共位置）
- 规格：保留基准淡色小眉弧、平直闭合小三角喙、不笑不嘟、双翅贴身收起、平和中立。
- 用途：所有触发式情绪片段的开头与结尾，也是待机画面。

## 1. 生气（angry）· 待肉眼验收

```
N → A1 起气抿嘴 → A2 小喊 → A3 大怒 → S1 提脚 → S2 踩下 → A4 收势 → N
```

| 帧 | 文件 | 眉 | 嘴 | 翅/脚 | 说明 |
|---|---|---|---|---|---|
| N | `angry_keyframes/graded/frame_00_neutral.png` | 淡眉弧 | 平嘴闭合 | 翅贴身 | 进出场常态 |
| A1 | `angry_keyframes/graded/frame_01_pout.png` | 轻倒八字下压 | 闭口抿成小倒三角 | 翅贴身 | 起气 |
| A2 | `angry_keyframes/graded/frame_02_shout.png` | 明显紧锁倒八字 | 小倒三角喊叫 | 翅两侧微张 | 生气小喊 |
| A3 | `angry_keyframes/graded/frame_03_rage.png` | 倒八字压低挤近 | 大张喊叫 | 翅抬起张开 | 大怒峰值 |
| S1 | `angry_keyframes/graded/frame_05_raise.png` | 细倒八字 | 大张喊叫 | 自身左脚（画面右侧）抬起离地，重心在右脚 | 跺脚提脚 |
| S2 | `angry_keyframes/graded/frame_06_stomp.png` | 细倒八字 | 大张喊叫 | 双翅收回贴身、双脚踩实、身体微沉，大小比例与其他帧一致不放大 | 跺脚踩下 |
| A4 | `angry_keyframes/graded/frame_04_reset.png` | 松开放平（余怒） | 闭合抿起不笑 | 翅贴身 | 段内收势，非常态 |

- 跺脚=S1 提脚→S2 踩下两个姿态，不用同帧上下平移（那只是震动）。
- 预览：`angry_keyframes/angry_loop_preview.gif`（情绪段内部硬切，≈3.17s/12fps，待验收）。
- 状态：关键帧已定稿、整体校色完成；待验收后按 `N→…→N` 接模拟器。

## 2. 悲伤（sad）· 待肉眼验收

```
N → S1 难过初起 → S2 委屈加深 → S3 伤心峰值 → N
```

| 帧 | 文件 | 眉 | 嘴 | 翅/头 |
|---|---|---|---|---|
| N | `angry_keyframes/graded/frame_00_neutral.png` | 淡眉弧 | 平嘴闭合 | 翅贴身 |
| S1 | `sad_keyframes/graded/frame_01_sad.png` | 细悲伤眉（内侧微抬、尾下垂） | 轻下撇小嘴 | 翅贴身微垂 |
| S2 | `sad_keyframes/graded/frame_02_wronged.png` | 悲伤眉更下垂 | 闭合喙、嘴角轻下撇（不张嘴） | 翅稍垂、眼神低垂 |
| S3 | `sad_keyframes/graded/frame_03_peak.png` | 细浅悲眉、尾端更垂（不加深变粗） | 闭合喙、轻下撇（不张嘴、不哭嘴） | 头微低、翅无力低垂 |

- 纯表情无位移；预览待关键帧验收后按 `N→S1→S2→S3→N` 程序排帧。
- 悲伤≠生病：生病需半睁困眼、腮红减淡、身体更塌等专属线索，单独建帧。

## 3. 睡觉（sleep）· 待机状态，单帧待验收

非触发情绪，不做递进序列；单帧 `Z1`，可配极轻呼吸/眨眼循环。

| 帧 | 文件 | 眼 | 嘴 | 翅/头 |
|---|---|---|---|---|
| Z1 | `sleep_keyframes/graded/frame_01_sleeping.png` | 闭合平缓下弯弧线（无眼珠无眼白） | 闭合小三角喙 | 双脚站基线、头微前垂、翅放松（站着打盹，不躺卧） |

- Zzz、被子、枕头走 UI 叠加，不烤进角色帧；躺卧深睡仅在需要独立夜间状态时另做。

## 4. 惊讶（surprise）· 轻量情绪，2 帧待验收

```
（回待机时）N → E1 轻惊讶 → E2 大吃惊 → N
```

| 帧 | 文件 | 眉 | 嘴 | 翅/眼 |
|---|---|---|---|---|
| E1 | `surprise_keyframes/graded/frame_01_startled.png` | 细眉微抬 | 小嘴微张 | 翅轻离身；黑圆眼不变 |
| E2 | `surprise_keyframes/graded/frame_02_shocked.png` | 细眉高挑 | 小圆 O 嘴 | 翅抬起、微后缩；黑圆眼不变 |

- 吃惊不靠把眼睁大加白圈，靠挑眉+O 嘴+抬翅；眼睛始终照基准纯黑圆、无眼白。

| 帧 | 文件 | 眉 | 嘴 | 翅/头/眼 |

|---|---|---|---|---|

## 8. 开心（happy）· 历史版本，待按 PU-060 重构

目标序列链（触发式，编号用 K 避开害羞 H）：

```
N → K1 蹲身准备 → K2 蹬地起跳 → K3 到顶开心 → K4 落地缓冲 → K5 小跳/复位 → N
```

| 帧 | 角色 | 说明 |
|---|---|---|
| N | 常态 | 进出场 |
| K1 | 蹲身准备 | 下沉蓄势 |
| K2 | 蹬地起跳 | 向上起势、翅轻抬 |
| K3 | 到顶开心 | 月牙笑眼、大笑、翅轻扬（峰值） |
| K4 | 落地缓冲 | 身体微沉站稳 |
| K5 | 小跳/复位 | 收翅回正，接 N |

- 现状：`happy_keyframes/`（六姿态关键帧）与 `happy_keyframes/v2_strict/`（AI 5s 方向预览 + 模拟器 `--happy-demo`）为历史版本，曾用 AI 视频单源循环。
- 待办：按 PU-060 改为 `N→K1→…→K5→N`，首尾用定稿常态帧；跳跃高低差由程序垂直位移表达，帧内不画腾空、不压扁拉长；不另插休息帧。

## 9. 待扩展情绪与候选状态

新增触发情绪按同一模板：先定常态 N 衔接，再列递进帧 A#、动作帧 S#、收势 B#，补帧只补缺失姿态，不为补间反复调 AI 视频。

- **轻量情绪（1–2 帧）**：疑惑（歪头+单眉+问号 UI，问号走 UI 不烤进帧）。
- **待机/状态（单张静态，不做序列）**：发懵、发呆、放空、无聊、生病；生病≠悲伤，需半睁困眼、腮红减淡、身体更塌等专属线索。
