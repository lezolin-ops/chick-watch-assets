# 小鸡关键帧素材规范（AI 关键帧 / 帧动画通用）

> 适用：后续所有整身动作（开心、招手、喂食反应等）与可复用部件的 AI 关键帧生产。
> 目的：让设计源稿、定稿打包帧、程序补间三者分工清晰，换人可接力，不在静态帧里硬做位移和缩放。

## 一、两层目录分离

```
assets/
├─ chick_character_design_pack/        # 设计区：AI 大图源稿、关键帧草案、预览，待抠待缩放
│   └─ <动画名>_keyframes/             # 一个动作一个文件夹
│       ├─ frame_01_描述.png
│       ├─ frame_02_描述.png
│       ├─ README.md（帧表）
│       └─ *_preview.gif（临时预览，不进固件）
└─ runtime/chick/                      # 运行区：抠透明、缩到规格、可直接打包进固件
    └─ <动画名>/                       # 定稿帧，与设计区同名对应
```

- 设计区大图（2048）只用于方向验收，**不直接进固件**。
- 整身动作与独立部件分夹：部件（嘴 `beak_v2`、翅膀 `wing_frames`）单独建夹，不混进某个整身动画。

## 二、画布与规格（整身动作）

| 项 | 规格 | 说明 |
|---|---|---|
| 定稿画布 | **192×192 RGBA** | 与现有 walk/daily/states 整身帧一致；显示窗口固定 192，不放大画布 |
| 背景 | RGBA 透明 | 设计稿可临时白底，定稿必须抠透明 |
| 水平居中 | 角色中心 x≈96 | |
| 脚底基准线 | 贴下方基准 | 站立/落地帧脚底对齐同一基线 |
| 头顶安全边距 | ≥25px | 对应主跳上移 22px，避免腾空头顶被裁；动作更夸张时再加大，仍是"帧内留边"而非放大画布 |
| 部件层 | 按现有小尺寸（嘴 32×36、翅 64×64） | 部件是叠加层，不走 192 |

**不放大画布**：显示窗口固定 192，把 PNG 做大只会被压回、降低分辨率，不会多出可见空间。

## 三、等体积与位移原则（关键）

- **跳跃高低差靠程序位移（translate_y），不靠把某帧缩小/放大来凑。**
- **等体积压缩**：落地压扁、蹬地拉长只改身体形状（横向撑开补偿纵向压扁），视觉体积保持一致，不整体缩小。
- 单张关键帧不画死世界坐标位置；位移曲线、挤压拉伸幅度由程序在时间线上插值施加。
- 静态预览 GIF 只用于判断动作顺序与表情连贯，不用于衡量比例精度。

## 四、命名与帧表

- 文件名 `frame_XX_描述.png`，两位序号即播放顺序（`frame_01_prepare_crouch.png`）。
- 每个动作夹配 `README.md` 帧表：帧号、时间点、位移、挤压 sx/sy、姿态、表情、对应程序化时间线。
- 一次性动作（如开心 1600ms）与循环动作（如 idle）分开标注；循环动作须保证首尾帧可无缝衔接。

## 五、生产流程

1. 以已确认母版（`runtime/chick/sprite_front_256.png`）为身份锚点，用图生图逐帧衍生，保持身份不变量；
2. 设计区出关键帧草版 → 临时预览 GIF 验收动作顺序与表情；
3. 方向确认后：抠 RGBA 透明 → 等比缩到 192 → 居中、脚底贴线、头顶留边 → 等体积核对；
4. 定稿存入 `runtime/chick/<动画名>/`，设计区源稿保留；
5. 帧表与决策同步记录到 `PRODUCT_UPDATES.md` 与对应动画说明文档。

## 六、身份不变量（所有动作共用）

柠檬黄圆润椭球身体、头顶三撮呆毛、黑色圆眼带白高光、两团粉色圆腮红、哑光橙三角喙、橙色三趾脚、圆润短三瓣小翅膀；扁平柔和 2D 平涂，无硬描边。
