# 开心点击回应 · AI 关键帧帧表（happy）

> 状态：**设计草版（待视觉验收）**。本目录为设计源稿（2048×2048、RGB 白底、未抠透明、未缩放），**未接入固件、未进 `runtime/`**。
> 用途：作为现有程序化开心（`firmware/main/pet.c` `happy_progress_cb`，1600ms 单条时间线）的关键帧方向参考 / 后续替代素材。中间补间由程序 smoothstep 插值，不逐帧 AI 绘制。
> 通用生产规范见上级目录《关键帧素材规范.md》。

## 一、动作定位

一次性「点击开心回应」，总长 **1600ms**，非循环。情绪：轻快、开心、被回应。笑眼区间 150–1400ms，结束恢复圆眼。

## 三、角色身份不变量（每帧必须一致）

柠檬黄圆润椭球身体、头顶三撮呆毛、黑色圆眼带一颗白高光、两团粉色圆腮红、哑光橙三角喙、橙色三趾脚、圆润短三瓣小翅膀；扁平柔和 2D 平涂，无硬描边。

## 四、定稿待办（视觉方向确认后执行）

1. 白底抠为 RGBA 透明；
2. 等比缩到 192×192 统一画布，水平居中，脚底贴基准线，头顶留约 25px 安全边距（对应主跳 −22px）；
3. 等体积原则：压扁/拉长只改身体形状，不整体缩小，六帧视觉体积一致；
4. 笑眼 F2–F5 连贯，F6 收回圆眼；
5. 定稿帧另存到 `runtime/chick/happy/`，本目录保留设计源稿。

## 七、单跳 + 身体等比调整（2026-10-17，待验收）

- **去掉第二次小弹跳**：用户要求"跳起下降后去掉小弹跳"。demo 时间线删去 F5 小跳帧（slot 4）与落地后 −9px echo，只保留一次主跳（到顶 −22px）→ 落下 → 复位。流程：F1 准备(0–150) → F2 蹬地(150–250) → F3 到顶(250–700) → F4 落地(700–950) → F6 复位(950–1600)。
